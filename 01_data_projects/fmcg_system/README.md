## FMCG POS & Inventory Data System

### Objective
To design a database-driven point-of-sale and inventory system for a fast-moving consumer goods (FMCG) retail setting.

---

### Project Context
This project was developed as part of a database systems course and applied data modeling concepts to a retail operations scenario. The system was designed to support product transactions, inventory updates, and structured storage of sales records.

---

### System Overview
The proposed system supports a retail workflow where:
- Customer purchases are recorded through a point-of-sale process  
- Product inventory is updated based on completed transactions  
- Product and transaction records are stored in a structured database  

---

### My Contribution
- Designed the database schema for product and transaction records  
- Contributed to defining CRUD operations for managing inventory and sales data  
- Helped structure how transactional data is stored and updated within the system  

Other components, such as aggregation pipelines and broader system analytics, were developed collaboratively within the group.

---

### Key Features
- Product and transaction schema design  
- CRUD operations for product and transaction management  
- Structured support for inventory and sales record updates  
- NoSQL-oriented system design for flexible data handling
