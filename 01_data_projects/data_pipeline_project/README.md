## Predictive Modeling of Wine Quality

### Objective
To build a data workflow for analyzing physicochemical wine properties and predicting wine quality using machine learning models.

---

### Project Context
This project was developed collaboratively as part of a business intelligence course. It applied data preprocessing, exploratory analysis, and predictive modeling techniques to a real-world dataset in order to understand the factors associated with wine quality.

---

### Project Overview
The project focused on using measurable chemical properties of red and white wines to predict quality scores. The workflow included:
- combining and preparing datasets
- exploring distributions and feature relationships
- standardizing variables
- training and comparing multiple machine learning models

---

### My Contribution
- Contributed to the exploratory data analysis and presentation of findings  
- Helped interpret feature relationships and model results  
- Participated in structuring how the analysis was presented from business problem to model evaluation  

The modeling workflow and technical implementation were developed collaboratively within the team.

---

### Key Features
- Merged red and white wine datasets for broader analysis  
- Exploratory data analysis using histograms, scatterplots, boxplots, and a correlation matrix  
- Standardization of features before modeling  
- Comparison of multiple models, including Random Forest, CatBoost, Gradient Boosting, LightGBM, and AdaBoost
